# Nature Earth

## Descripción
**Nature Earth** es una plataforma web educativa dedicada a la consulta de biodiversidad y especies de fauna en todo el mundo. Permite explorar un globo terráqueo 3D interactivo, filtrar especies por categoría taxonómica y ubicación geográfica, consultar fichas detalladas con fuentes científicas verificadas y utilizar un chatbot asistente según el nivel de suscripción del usuario (*Casual*, *Estudiante* e *Investigador*).

### Características y tecnologías principales
- **Globo terráqueo 3D interactivo:** Visualización de especies con marcadores por categoría taxonómica utilizando `Globe.gl`.
- **Fuentes de información confiables:** Recolección de datos verificados desde *iNaturalist*, *IUCN Red List*, *NCBI Taxonomy* y *Semantic Scholar*.
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS y shadcn/ui.
- **Backend:** Java 17, Spring Boot 3.x, Spring Security y JWT.
- **Base de datos:** PostgreSQL con extensión PostGIS.
